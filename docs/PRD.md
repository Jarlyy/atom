📄 PRD.md — Interactive Atom & Molecule Visualizer
 
1. 📌 Обзор продукта
 
Веб-приложение для интерактивной визуализации атомов и электронной структуры. Пользователь может выбирать химические элементы и наблюдать их 3D-модель с электронами и оболочками.
 
Цель продукта — упростить понимание структуры атома для школьников и студентов через наглядную интерактивную модель.
 
 
---
 
2. 🎯 Цели продукта
 
Основные цели:
 
Упростить понимание атомной структуры
 
Дать наглядное представление электронных оболочек
 
Обеспечить интерактивное взаимодействие с атомом
 
 
Успех продукта:
 
Пользователь может выбрать элемент и понять его структуру за < 1 минуты
 
Интерактивность помогает лучше запоминать конфигурацию
 
 
 
---
 
3. 👥 Целевая аудитория
 
школьники (10–18 лет)
 
студенты (первый курс химии/физики)
 
самообучающиеся пользователи
 
 
Основная проблема:
 
Пользователи не могут визуально представить:
 
структуру атома
 
расположение электронов
 
принцип электронных оболочек
 
 
 
---
 
4. 🧠 MVP (минимальная версия)
 
Обязательные функции:
 
1. Выбор элемента
 
пользователь выбирает элемент из списка (периодическая таблица)
 
данные загружаются из локального JSON
 
 
2. 3D визуализация атома
 
ядро (протоны/нейтроны — упрощённо)
 
электроны на оболочках
 
анимация вращения электронов
 
 
3. Электронная структура
 
отображение конфигурации (например: 2, 8, 1)
 
визуальное соответствие оболочкам

6. 🧭 UX / Пользовательский сценарий
