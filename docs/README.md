# Interactive Atom & Molecule Visualizer

## Назначение

Interactive Atom & Molecule Visualizer — образовательное frontend-приложение для интерактивной 3D-визуализации атомов и электронной структуры. MVP помогает школьникам, студентам и самообучающимся пользователям увидеть ядро, электронные оболочки и распределение электронов для выбранного химического элемента.

## Источники требований

- Product requirements: `docs/PRD.md`.
- Операционный контекст реализации: `memory_bank/`.

## Архитектура MVP

Приложение реализуется как Next.js App Router проект на TypeScript. Backend отсутствует: данные элементов хранятся локально и используются клиентскими компонентами.

Текущий статус: ранний рабочий прототип (~20% готовности по оценке пользователя). В проекте есть базовая визуализация атома и несколько UX-инструментов, но это не завершенный продукт/MVP.

## Основные подсистемы

- 3D-визуализация: `AtomScene` отображает ядро, энергетические уровни `n`, `s/p/d/f`-орбитали как траектории и электроны, движущиеся по занятым траекториям, через Three.js / React Three Fiber.
- Электронная конфигурация: `buildElectronLevels` распределяет электроны по подуровням в порядке заполнения для элементов H-Og, учитывает базовые исключения конфигураций и раскладывает электроны по орбиталям подуровня.
- Выбор элемента: `ElementSelector` позволяет выбрать элемент из полного локального набора H-Og.
- Информационная панель: `InfoPanel` показывает название, атомный номер и электронную конфигурацию.
- Фокус орбиталей: `OrbitalFocusPanel` управляет выбранной орбиталью и пошаговым заполнением электронов; `AtomScene` подсвечивает активную орбиталь, приглушает остальные и замедляет их электроны.
- UI primitives: интерфейс построен на shadcn/ui-compatible компонентах `Button`, `Card`, `Badge` с Tailwind CSS v4 и CSS variables theme.
- Данные элементов: локальная модель данных содержит atomic number, количество протонов/нейтронов/электронов и shells.
- Клиентское состояние: выбранный элемент хранится в UI-слое без серверной синхронизации.

## Поток пользователя

1. Главный экран открывается с Hydrogen по умолчанию.
2. Пользователь вращает 3D-модель мышью и меняет масштаб колесом.
3. Пользователь открывает выбор элемента и выбирает другой элемент.
4. Сцена и информационная панель обновляются по выбранным данным.
5. Пользователь выбирает орбиталь или шаг заполнения, чтобы рассмотреть отдельную траекторию без визуального шума.

## Технические ограничения

- MVP полностью client-side.
- Не использовать внешние API и серверную логику.
- Сохранять стабильную производительность WebGL на среднем ПК.
- Не перегружать сцену избыточным количеством объектов.
- Формы `s/p/d/f`-орбиталей учебно упрощены как видимые траектории движения электронов; облака вероятности в MVP не отображаются.
- Использовать Bun как пакетный менеджер.
- Для UI использовать shadcn/ui-compatible primitives и Tailwind CSS v4.
- Проверять измененный код через Biome, не запускать Biome для Markdown-файлов.

## Исключено из MVP

- Химические реакции.
- Молекулы.
- Физически точная геометрия квантовых орбиталей.
- Расчет реальной физики.
