# Active Context

## Текущий фокус

Проект находится на стадии раннего рабочего прототипа (~20% готовности по оценке пользователя), а не завершенного MVP. Есть базовый показ атома, выбор всех элементов H-Og, черновая `s/p/d/f`-визуализация и Orbit focus, но до полноценного образовательного продукта остаются научная/визуальная доводка, объяснения, UX-фильтры, адаптивность, тесты и деплой.

## Активная задача

- Переделка 3D-визуализации атома: электронная оболочка должна подразделяться на энергетические уровни, уровни — на подуровни `s/p/d/f`, подуровни — на отдельные орбитали с электронами.
- Memory Bank создан и синхронизирован.
- `docs/README.md` создан как источник архитектурной правды.
- Next.js приложение создано на Bun.
- Реализованы 3D-сцена, локальные данные H-Og, выбор элемента и информационная панель.
- UI-слой переведен на `Button`, `Card`, `Badge` из `src/components/ui/`.
- Реализован расчет электронной конфигурации, подуровней и орбиталей в `src/lib/electronConfiguration.ts`.
- Облака вокруг электронов удалены; реализованы разные траектории орбиталей в `AtomScene`.
- `AtomScene` переделан на отображение занятых `spdf`-орбиталей как траекторий движения электронов; облака орбиталей удалены.
- Добавляется режим фокуса орбиталей: ручной выбор орбитали, приглушение остальных траекторий, замедление неактивных электронов и пошаговое заполнение.
- Memory Bank приведен к правилам `AGENTS.md`: канонический процент считается только по `Project Deliverables`, используются допустимые статусы deliverables, обязательные файлы присутствуют.

## Решения

- Источник требований: `docs/PRD.md`.
- Источник архитектурной правды: `docs/README.md`.
- MVP реализуется без backend, только frontend/client-side.
- Для MVP используется локальный TypeScript-модуль данных `src/data/elements.ts`.
- Состояние выбранного элемента хранится в `src/app/page.tsx` через `useState`.
- Ручного состояния orbital view нет: уровни, подуровни, орбитали и электроны выводятся автоматически из числа электронов элемента.
- shadcn/ui используется как локальные primitives, добавленные в `src/components/ui/`, с конфигурацией `components.json`.

## Неопределенности

- Текущая оценка готовности — приблизительная; пользователь считает проект завершенным примерно на 20%.
