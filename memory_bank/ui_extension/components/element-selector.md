# ElementSelector

## Назначение

`ElementSelector` отображает большую overlay-таблицу элементов H-Kr и обновляет выбранный элемент.

## Файл

- `src/components/ElementSelector.tsx`

## Поведение

- Компонент рендерится только при `isOpen=true`.
- Overlay закрывается по кнопке `Close`, клику по фону или после выбора элемента.
- Выбранный элемент подсвечивается.
- Кнопки элементов построены на shadcn/ui-compatible `Button` с `variant="outline"`.
- Каждый элемент отображает символ, атомный номер и название.
- Выбор передается наверх через `onSelect`.
- Правая панель содержит только компактный вызов `Choose element`, чтобы не перегружать viewport.
