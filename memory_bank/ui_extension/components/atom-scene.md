# AtomScene

## Назначение

`AtomScene` визуализирует атом через React Three Fiber: ядро, энергетические уровни, `s/p/d/f`-орбитали как траектории и электроны, движущиеся по занятым траекториям.

## Файл

- `src/components/AtomScene.tsx`

## Поведение

- Камера направлена на атом и поддерживает orbit controls.
- Пользователь может вращать сцену мышью и менять масштаб колесом.
- Группа атома медленно вращается для живого превью.
- Энергетические уровни отображаются через направляющие кольца и подписи `K/L/M/N` + `n=1..4`.
- Каждый уровень делится на `s/p/d/f`-орбитали согласно электронной конфигурации.
- Типы `s/p/d/f` имеют разное число траекторий: `s` — 1, `p` — 3, `d` — 5, `f` — 7.
- Визуальные траектории отличаются: `s` — круговая, `p` — восьмерочная в трех ортогональных плоскостях, `d` — пять отдельных учебных вариантов `dxy/dyz/dxz/dx²-y²/dz²`, `f` — семь различимых многолепестковых вариантов.
- Электроны двигаются по конкретной траектории; одна траектория содержит максимум 2 электрона.
- Выбранная орбиталь подсвечивается более толстой и яркой траекторией.
- Невыбранные орбитали приглушаются, а электроны на них двигаются медленнее.
- При пошаговом заполнении сцена строится только по текущему количеству видимых электронов и автоматически фокусирует последний заполненный подуровень.
- Облака вероятности не отображаются.
- Заполнение орбиталей внутри подуровня следует упрощенному правилу Хунда: сначала по одному электрону, затем пары.
- Количество частиц ядра ограничено, чтобы не перегружать WebGL сцену.

## Входные данные

- `ChemicalElement` из `src/data/elements.ts`.
- `selectedOrbitalId`, `visibleElectrons`, `onSelectOrbital` для режима фокуса и пошагового заполнения.
