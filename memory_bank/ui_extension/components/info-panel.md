# InfoPanel

## Назначение

`InfoPanel` показывает учебную информацию по выбранному элементу.

Интерфейс построен на shadcn/ui-compatible `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`.

## Файл

- `src/components/InfoPanel.tsx`

## Данные

- Название.
- Символ.
- Атомный номер.
- Количество протонов, нейтронов и электронов.
- Электронная конфигурация `spdf`.
- Список энергетических уровней с занятыми `s/p/d/f`-орбиталями, количеством траекторий и электронов.
