# OrbitalFocusPanel

## Назначение

`OrbitalFocusPanel` помогает рассматривать перегруженную 3D-сцену: показывает компактное состояние текущего фокуса, дает dropdown-выбор подуровня и конкретной орбитали-ориентации внутри него и управляет пошаговым заполнением электронов.

## Файл

- `src/components/OrbitalFocusPanel.tsx`

## Поведение

- В правой панели показывает текущий фокус, dropdown `Subshell`, dropdown `Orientation`, кнопку `Reset`, пошаговое заполнение и легенду.
- `Subshell` выбирает весь подуровень и синхронизирует список доступных ориентаций.
- `Orientation` содержит `All` для выбора всего подуровня и конкретные заполненные траектории/ориентации: например `px/py/pz`, `dxy/dyz/dxz/dx²-y²/dz²`, варианты `f`.
- Для `f` используются подписи стандартных учебных вариантов: `fxyz`, `fz(x²-y²)`, `fx(x²-3y²)`, `fy(3x²-y²)`, `fxz²`, `fyz²`, `fz³`.
- Dropdown-контролы стилизованы как темные компактные поля с кастомным индикатором раскрытия, чтобы не выглядеть как системные элементы без оформления.
- Клик по подуровню передает его id в `AtomScene` и подсвечивает все заполненные траектории подуровня.
- Клик по отдельной траектории передает id конкретной орбитали в `AtomScene` и подсвечивает только эту ориентацию.
- `Reset` возвращает состояние `Overview`: все орбитали отображаются без ручного фокуса и без автофокуса на последнем заполненном подуровне.
- Кнопка `Reset` снимает ручной фокус.
- Кнопки `Previous` и `Next` меняют количество видимых электронов.
- Кнопка `Full` возвращает полное заполнение выбранного элемента.
- Цветовая легенда `s/p/d/f` вынесена в UI, чтобы не перегружать 3D-сцену.
