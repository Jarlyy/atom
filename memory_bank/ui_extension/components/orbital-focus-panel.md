# OrbitalFocusPanel

## Назначение

`OrbitalFocusPanel` помогает рассматривать перегруженную 3D-сцену: выбирает конкретную орбиталь и управляет пошаговым заполнением электронов.

## Файл

- `src/components/OrbitalFocusPanel.tsx`

## Поведение

- Показывает список занятых `s/p/d/f`-орбиталей выбранного элемента.
- Клик по орбитали передает `selectedOrbitalId` в `AtomScene`.
- Кнопка `Reset` снимает ручной фокус.
- Кнопки `Previous` и `Next` меняют количество видимых электронов.
- Кнопка `Full` возвращает полное заполнение выбранного элемента.
- Цветовая легенда `s/p/d/f` вынесена в UI, чтобы не перегружать 3D-сцену.
