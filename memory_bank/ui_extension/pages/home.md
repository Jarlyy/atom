# Home Page

## Назначение

Главная страница показывает интерактивную 3D-модель выбранного атома и панель управления элементом.

## Файл

- `src/app/page.tsx`

## Компоненты

- `AtomScene` — центральная 3D-сцена с ядром, энергетическими уровнями, `s/p/d/f`-орбиталями/траекториями и электронами.
- `InfoPanel` — карточки с названием, атомным номером, протонами, нейтронами, электронами, `spdf`-конфигурацией и списком уровней/орбиталей.
- `ElementSelector` — сетка выбора элементов H-Ca.
- `Card`, `CardHeader`, `CardContent`, `Badge` — shadcn/ui-compatible primitives для layout и статуса атомного номера.

## Поток данных

1. Страница загружает массив `elements` из `src/data/elements.ts`.
2. `Hydrogen` выбран по умолчанию.
3. Выбор элемента обновляет состояние `selectedElement`.
4. `AtomScene` получает обновленный элемент через props и пересчитывает уровни, `s/p/d/f`-орбитали и электронные траектории.
5. `InfoPanel` получает обновленный элемент через props и показывает `spdf`-конфигурацию.

## UX

- Desktop-first компоновка на Tailwind utilities: сцена слева, панель управления справа.
- На мобильных экранах панели складываются в одну колонку.
- Темная тема соответствует PRD.
