# Home Page

## Назначение

Главная страница показывает интерактивную 3D-модель выбранного атома и панель управления элементом.

## Файл

- `src/app/page.tsx`

## Компоненты

- `AtomScene` — центральная 3D-сцена с ядром, энергетическими уровнями, `s/p/d/f`-орбиталями/траекториями и электронами.
- `InfoPanel` — карточки с названием, атомным номером, протонами, нейтронами, электронами, `spdf`-конфигурацией и списком уровней/орбиталей.
- `OrbitalFocusPanel` — панель выбора орбитали и пошагового заполнения электронов.
- `ElementSelector` — overlay-периодическая таблица выбора всех элементов H-Og, открываемая кнопкой `Choose element`.
- `Card`, `CardHeader`, `CardContent`, `Badge` — shadcn/ui-compatible primitives для layout и статуса атомного номера.

## Поток данных

1. Страница загружает массив `elements` из `src/data/elements.ts`.
2. `Hydrogen` выбран по умолчанию.
3. Выбор элемента обновляет состояние `selectedElement`.
4. Выбор элемента сбрасывает `selectedOrbitalId` и возвращает `visibleElectrons` к полному числу электронов элемента.
5. Кнопка `Choose element` открывает overlay `ElementSelector`.
6. `OrbitalFocusPanel` обновляет `selectedOrbitalId` или `visibleElectrons`.
7. `AtomScene` получает обновленный элемент, фокус и шаг заполнения через props и пересчитывает уровни, `s/p/d/f`-орбитали и электронные траектории.
8. `InfoPanel` получает обновленный элемент через props и показывает `spdf`-конфигурацию.

## UX

- Desktop-first компоновка на Tailwind utilities: сцена слева, панель управления справа.
- На desktop страница фиксируется в `h-screen` без общей прокрутки; правая колонка начинается с закрепленной компактной кнопки выбора элемента, затем содержит InfoPanel и OrbitalFocusPanel.
- Средняя область правой панели с `InfoPanel` имеет собственную прокрутку, чтобы секция Selected element не обрезалась при нехватке высоты.
- На мобильных экранах панели складываются в одну колонку.
- Темная тема соответствует PRD.
