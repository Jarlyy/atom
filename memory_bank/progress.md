# Progress

## Статус

- Проект переоценен: текущая пользовательская оценка готовности около 20%, это ранний рабочий прототип, а не завершенный MVP.
- Канонический процент по `memory_bank/projectbrief.md`: 20% completed deliverables; остальные ключевые deliverables находятся в `in_progress` или `pending`.
- Реализована базовая основа: Next.js App Router приложение, интерактивная 3D-сцена, локальные данные H-Og, overlay-селектор элементов и информационная панель.
- Локальная модель данных расширена до всех 118 элементов H-Og.
- Исправлена `d`-траектория для элементов после Ca: она больше не схлопывается в прямую линию через ядро.
- Масштаб `d`-траекторий увеличен, чтобы они визуально читались крупнее `p`-орбиталей.
- Добавлен режим фокуса орбиталей: выбор активной орбитали, приглушение остальных, замедление неактивных электронов и пошаговое заполнение электронов.
- Камера `AtomScene` отодвинута и расширен диапазон zoom out, чтобы крупные элементы помещались в кадр.
- Layout главной страницы уплотнен до `h-screen` без общей прокрутки на desktop; правая панель и сетка элементов уменьшены.
- Выбор элементов перенесен в overlay-таблицу, открываемую кнопкой `Choose element`, чтобы правая панель оставалась компактной.
- Кнопка `Choose element` перенесена наверх правой панели и больше не выталкивается длинным списком орбиталей у элементов после Ca.
- Интерфейс переведен на shadcn/ui-compatible primitives и Tailwind CSS v4.
- Ошибочный ручной переключатель орбиталей удален; уровни переведены на структуру подуровней `s/p/d/f` с орбиталями и электронами.
- Облака вокруг электронов удалены; электроны двигаются по разным траекториям орбиталей `s/p/d/f`.
- `AtomScene` переделан на иерархию `уровень -> подуровень s/p/d/f -> орбиталь -> электрон`; орбитали больше не выглядят как случайные траектории, а отображаются как учебные формы `s/p/d/f`.
- `InfoPanel` показывает `spdf`-конфигурацию и список уровней с подуровнями, количеством орбиталей и электронов.
- По уточнению пользователя облака вероятности удалены: `s/p/d/f` теперь отображаются как траектории движения электронов.
- Исправлено смешивание уровней: `2p` и другие внешние `spdf`-траектории теперь строятся вокруг радиуса своего энергетического уровня и не проваливаются к `1s`.
- После уточнения формы `p`: `p` снова отображается как локальная восьмерочная траектория, но ее центр вынесен на радиус соответствующего уровня, чтобы не смешиваться с `1s`.
- После уточнения пользователя центр `s/p/d/f`-траекторий возвращен в центр атома; принадлежность уровню теперь задается масштабом траектории, а не смещением центра.
- Ориентация `p`-орбиталей исправлена: три `p`-траектории выровнены по осям `x/y/z`, а не разведены "снежинкой".
- `p`-орбитали разведены по трем ортогональным плоскостям: `px` в `xy`, `py` в `yz`, `pz` в `xz`.
- Масштаб `p`-траекторий увеличен: `2p` теперь визуально больше `2s` на том же энергетическом уровне.
- `.gitignore` расширен для исключения локальных артефактов Next.js/Bun/tooling/IDE/log/temp/env перед отправкой проекта на GitHub.
- Расстояние между энергетическими уровнями увеличено, а шаг между `s/p/d/f`-орбиталями внутри одного уровня уменьшен для лучшей читаемости уровней.
- Проверки `bun run format` и `bun run build` завершились успешно.
- Добавлена полная периодическая система H-Og; электронная конфигурация расширена до 7p с базовыми исключениями, а оболочки элементов теперь рассчитываются из конфигурации.
- `ElementSelector` теперь раскладывает элементы по классической 18-колоночной структуре периодической таблицы с отдельными строками лантаноидов и актиноидов.
- Раскладка `ElementSelector` уточнена до более классического вида: основная таблица содержит периоды 1-7 и группы 1-18, а лантаноиды/актиноиды вынесены отдельным блоком снизу с placeholders `57-71` и `89-103` в основной сетке.
- Исправлены учебные `d/f`-траектории в `AtomScene`: пять `d`-орбиталей теперь имеют отдельные формы/ориентации `dxy/dyz/dxz/dx²-y²/dz²`, а семь `f`-орбиталей больше не отображаются одной условной кривой.
- Добавлен выбор конкретной заполненной орбитали-ориентации внутри подуровня: пользователь может выбрать весь `3d` или отдельно `dxy/dyz/dxz/dx²-y²/dz²` и соответствующие траектории подсвечиваются в `AtomScene`.
- Улучшен дизайн `OrbitalFocusPanel`: список фокуса переведен с плотной сетки кнопок на компактные цветные карточки подуровней с отдельной кнопкой `All` и pill-кнопками ориентаций.
- UX выбора орбиталей переделан в overlay-карту: правая панель больше не содержит длинный список, поэтому `InfoPanel` не перекрывается, а выбор подуровней/ориентаций вынесен в полноэкранную карту.
- По UX-уточнению overlay-карта заменена на компактные dropdown-контролы `Subshell` и `Orientation` прямо в `OrbitalFocusPanel`, без длинных списков и без перекрытия `InfoPanel`.
- `Reset` в `OrbitalFocusPanel` теперь возвращает общий вид `Overview`: `AtomScene` не автофокусирует последний заполненный подуровень и не приглушает остальные орбитали.
- Замедлено движение электронов в `Overview`-режиме, улучшен внешний вид dropdown-контролов выбора орбитали, а `InfoPanel` уплотнен и помещен в прокручиваемую область, чтобы Selected element не обрезался.

## Known Issues / Backlog

- Формы `s/p/d/f` остаются учебными черновыми траекториями и требуют отдельной визуальной/методической доводки.
- Сложные атомы все еще могут перегружать сцену; нужны фильтры, режимы слоев и более аккуратная визуальная иерархия.
- Нужен полноценный образовательный слой: объяснения, подсказки, легенды, сценарии заполнения и описания правил.
- Нужна лучшая адаптивность под разные экраны, особенно mobile/tablet.
- Нужны тесты, visual regression, performance checks, CI/CD и деплой.
- Memory Bank должен дальше считать процент только по `Project Deliverables` из `projectbrief.md`; Changelog не является источником процента.
