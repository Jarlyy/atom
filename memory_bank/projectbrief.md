# Project Brief

## Цель проекта

Interactive Atom & Molecule Visualizer — образовательное веб-приложение для интерактивной 3D-визуализации атомов и электронной структуры. MVP фокусируется только на атомах: пользователь выбирает химический элемент и видит упрощенную 3D-модель ядра, электронных оболочек и электронов.

## Scope MVP

- Next.js App Router приложение на TypeScript.
- Полностью client-side без backend/API.
- 3D-сцена через Three.js / React Three Fiber.
- Локальный JSON с 10-20 элементами от Hydrogen до Calcium.
- Выбор элемента через периодическую таблицу/селектор.
- Отображение названия, атомного номера и электронной конфигурации.
- Интерактивное вращение и zoom модели.
- Энергетические уровни делятся на подуровни `s/p/d/f`; подуровни содержат орбитали, на которых размещаются электроны.

## Out Of Scope MVP

- Химические реакции.
- Молекулы.
- Сложные квантовые орбитали.
- Серверная логика и внешние API.
- Расчет реальной физики.
