# System Patterns

## Архитектура

MVP планируется как single-page frontend на Next.js App Router. Backend отсутствует, данные элементов поставляются из локального JSON/TypeScript-модуля.

## Основные модули

- `AtomScene`: 3D-сцена атома на React Three Fiber.
- `ElementSelector`: UI выбора элемента из локального набора данных.
- `InfoPanel`: отображение свойств выбранного элемента.
- `buildElectronLevels`: расчет уровней, подуровней и орбиталей для размещения электронов.
- `src/components/ui/*`: shadcn/ui-compatible primitives для карточек, кнопок и бейджей.
- `atomState`: состояние выбранного элемента на клиенте.
- `electronRenderer`: визуальное расположение электронов по орбиталям подуровней.
- `electronConfiguration`: логика распределения электронов по подуровням `s/p/d/f` и орбиталям.

## Потоки данных

1. Пользователь выбирает элемент в UI.
2. Состояние выбранного элемента обновляется в клиентском компоненте.
3. `buildElectronLevels` рассчитывает подуровни и орбитали по числу электронов.
4. `AtomScene` получает данные элемента и отображает ядро, энергетические уровни, занятые `s/p/d/f`-орбитали как траектории и электроны, движущиеся по этим траекториям.
5. `InfoPanel` получает данные элемента и показывает электронную конфигурацию.

## Ограничения

- Не использовать серверную логику для MVP.
- Не перегружать сцену большим количеством частиц.
- Сохранять минималистичный темный интерфейс.
- Новые UI-элементы строить на shadcn/ui-compatible primitives и Tailwind utilities.
- Форма `s/p/d/f`-орбиталей визуально упрощена как траектория движения электронов; облака вероятности не отображаются в текущем пользовательском варианте.
